## 使用示例

### 在 Qt 中初始化
```cpp
// 在 mainwindow.h 中添加
#include "PlantDisease.h"
std::unique_ptr<PlantDisease> diseaseDetector;

// 在 mainwindow.cpp 中初始化
diseaseDetector = std::make_unique<PlantDisease>(
    "assets/models/plant_disease.onnx",
    "assets/models/plant_disease_labels.txt"
);
```

### 执行病害检测
```cpp
// 从文件检测
auto results = diseaseDetector->inferFromFile(imagePath, 3);

// 从 Mat 检测
auto results = diseaseDetector->infer(mat, 3);

// 获取结果
for (const auto& r : results) {
    qDebug() << "病害:" << QString::fromStdString(r.name);
    qDebug() << "置信度:" << r.score;
    qDebug() << "是否健康:" << diseaseDetector->isHealthy(r.index);
    qDebug() << "植物名称:" << QString::fromStdString(diseaseDetector->getPlantName(r.index));
}
```
