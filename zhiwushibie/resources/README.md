# 资源文件夹

这个文件夹用于存放植物识别项目的各种资源文件。

## 文件夹结构

- `images/` - 存放图片资源
  - 植物图片
  - 测试图片
  - 示例图片
- `icons/` - 存放图标文件
  - 应用图标
  - UI图标
- `models/` - 存放模型文件
  - ONNX模型文件
  - 标签映射文件
- `data/` - 存放数据文件
  - 配置文件
  - 数据库文件

## 使用说明

1. 将植物图片放入 `images/` 文件夹
2. 支持的图片格式：JPG, PNG, BMP, TIFF
3. 建议图片尺寸：224x224 或 256x256 像素
4. 图片命名建议使用有意义的名称，便于管理

## 注意事项

- 请确保图片文件大小适中，避免影响应用性能
- 建议对图片进行预处理，确保质量良好
- 定期清理不需要的图片文件
